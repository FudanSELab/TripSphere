# 服务处理

# TripSphere AI 原生故障数据集蓝图

目标建议样本数：`F1` 约 30，`F2` 约 30，`F3` 约 10，`F4` 约 10，`F5` 约 40\-50。

| 子类                            | 典型错误（中文）                                  | 推荐注入点                                                   | 注入边界                                              | 建议样本数 |
| ------------------------------- | ------------------------------------------------- | ------------------------------------------------------------ | ----------------------------------------------------- | ---------- |

| F1\.2 Memory Fault              | 内存压力、OOM、内存泄漏、会话/草稿/索引状态被挤出 | `trip-chat-service`、`trip-itinerary-planner`、`trip-order-assistant`、`trip-itinerary-service`、`trip-order-service`、`postgres`、`mongodb`、`qdrant` | 进程堆内存边界，JVM/Python runtime 边界，索引构建边界 | 8          |
| F1\.3 Disk / IO Fault           | 磁盘满、IO 抖动、fsync 变慢、对象存储写入拖慢     | `postgres`、`mongodb`、`redis`、`qdrant`                     | 数据卷/对象存储/日志落盘边界                          | 4          |
| F1\.4 Process / Container Fault | 进程停止、容器暂停、重启风暴、冷启动变慢          | `trip-chat-service`、`trip-itinerary-planner`、`trip-order-assistant`、`trip-itinerary-service`、`trip-order-service`、`nacos`、`higress` | 服务实例边界、依赖发现边界、任务 worker 边界          | 7          |
